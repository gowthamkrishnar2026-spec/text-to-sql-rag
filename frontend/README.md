# Frontend

Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + Recharts dashboard for the Text-to-SQL system.
See the [root README](../README.md) for the full setup.

```bash
npm install
npm run dev      # http://localhost:3000  (backend expected at NEXT_PUBLIC_API_URL)
npm run lint
npm run build
```
